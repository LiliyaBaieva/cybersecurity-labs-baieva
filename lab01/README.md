## 🛡️ Аналіз безпеки паролів

Програма аналізує надійність пароля за шкалою 1-10, враховуючи його зв'язок з персональними даними користувача.

| Критерій оцінки | Вплив | Бали (±) |
| :--- | :--- | :---: |
| Довжина > 7 символів | Достатня довжина | +2 |
| Змішаний регістр (Aa) | Ускладнення брутфорсу | +2 |
| Наявність спецсимволів (!@#) | Найвищий внесок у захист | +2 |
| **Збіг з особистими даними** | **Критична вразливість** | **-3** |
| Повторювані символи | Слабкий шаблон | -2 |

## ⚙️ Технології реалізації

| Компонент | Технологія / Модуль | Призначення |
| :--- | :--- | :--- |
| **Основна мова** | Python 3.x | База програми. |
| **Аналітика тексту** | Модуль `re` (Regex) | Пошук спецсимволів, регістру та послідовностей. |
| **Введення даних** | Вбудована функція `input()` | Інтерактивний збір даних користувача. |
