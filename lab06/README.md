# Консольний застосунок Student 

Ці два консольні застосунки, написані на Python, використовують вбудовану базу даних SQLite для симуляції роботи системи пошуку студентів. Вони наочно демонструють ключову різницю між вразливим та безпечним кодом при роботі з базами даних.
Кожна програма створює власну базу даних (vulnerable_students.db або secure_students.db), заповнює її тестовими даними (включаючи конфіденційний запис "Адмін Секретар") і дозволяє користувачеві виконувати частковий пошук за іменем або групою (за допомогою оператора LIKE).

## Вразливий Застосунок (Students_Vulnerable.py)
Призначення: демонстрація вразливості SQL Injection (SQLI) та її наслідків.

### Механізм Вразливості:

Цей додаток створює SQL-запит шляхом прямої конкатенації рядка (f-string):

`sql_query = f"SELECT ... WHERE name LIKE '%{user_input}%' OR group_id LIKE '%{user_input}%'"`

Коли користувач вводить спеціально сформований рядок, він "закриває" лапки пошукового терміну і вставляє власний SQL-код, змінюючи початкову логіку запиту.

Тест на Ін'єкцію - вхідний пейлоад:  `' OR 1=1 --`

**Результат**: Запит змінюється на ... 
`WHERE name LIKE '%' OR 1=1 -- %'`. 

Оператор 1=1 завжди істинний, а -- коментує решту запиту. У результаті додаток повертає всі записи з таблиці, спричиняючи витік даних, включаючи конфіденційний secret_pin Адміна.

## Безпечний Застосунок (Students_Secure.py)

**Призначення**: демонстрація стандартного методу захисту від SQL Injection.

**Механізм Захисту** - цей додаток використовує параметризовані запити (або "плейсхолдери" ?):
```
sql_query = "SELECT ... WHERE name LIKE ? OR group_id LIKE ?"
cursor.execute(sql_query, (search_term, search_term))
```
Рушій бази даних SQLite обробляє вхідні дані окремо від команди SQL. 

Рядок user_input ніколи не інтерпретується як виконуваний SQL-код.

**Тест на Ін'єкцію** - вхідний пейлоад: `' OR 1=1 --`

**Результат**: Додаток шукає в базі даних запис, який буквально містить рядок `%' OR 1=1 -- %` як частину імені або групи. Оскільки такого запису не існує, пошук не дає результатів, і ін'єкція успішно блокується.
