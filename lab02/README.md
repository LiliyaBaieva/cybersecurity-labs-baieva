# Програма "Сравнительный анализ классических шифров"

## 1. Опис та Призначення

Ця консольна програма на Python реалізує два класичні алгоритми шифрування — Шифр Цезаря та Шифр Віженера — для демонстрації та порівняльного аналізу їхньої криптографічної стійкості.

Програма розроблена в рамках Технічного завдання Лабораторної роботи №2 і використовує ключі, згенеровані на основі персональних даних користувача, що підкреслює вразливість передбачуваних ключів.

## 2. Функціональні Можливості
| Функція | Деталі |
| :--- | :--- |
| Алгоритми | Шифр Цезаря (моноалфавітний) та Шифр Віженера (поліалфавітний). | 
|Генерація КлючівЦезар: | Сума цифр дня та місяця народження. |
| Віженер: | Прізвище користувача (латиницею). |
| Обробка Вводу | Приймає текст кирилицею або латиницею з автоматичною транслітерацією в латинський алфавіт для шифрування. |
| Аналіз | Виводить показник Унікальності Літер (Унікальність літер (%)) у шифротексті як індикатор стійкості до частотного аналізу. |
| Демонстрація | Виконує шифрування та перевірочне дешифрування для обох методів. |

## 3. Запуск Програми

Для роботи потрібен Python 3.x.
Збережіть код програми у файл cipher_analyzer.py.Запустіть програму через консоль:

```bash ```

``` python cipher_analyzer.py ```

Програма запитає необхідні дані для генерації ключів та тестовий текст.

## 4. Класифікація Стійкості

Програма наочно демонструє, що:
* Шифр Цезаря є нестійким (малий простір ключів).
* Шифр Віженера має вищу стійкість, проте використання короткого ключа на основі прізвища є його критичною вразливістю.
