## Запуск Програми

Програма запускається з командного рядка:Bash

```python LSBSteganography.py ```

## Принцип Роботи та Ввід

Програма автоматично проведе користувача через процес приховування та виявлення повідомлення:

Ввід: Запитує П.І.Б., Дату Народження та відносний шлях до файлу-контейнера.

Формат Контейнера: Обов'язково використовуйте зображення у форматі PNG (.png), оскільки LSB не працює надійно з JPEG через стиснення.

Приклад Вводу:Введіть П.І.Б. (для приховування): Liliia Baieva


Введіть Д.Н. (ДД.ММ.РРРР): 12.04.1987


Введіть назву файлу-контейнера (наприклад, lab03/my_photo.png): lab03/my_photo.png

2. ## Принцип Захисту (LSB)
Успішне застосування LSB-стеганографії демонструє, що приховати інформацію можна в незначущих бітах зображення, захищаючи конфіденційність без видимих змін у файлі.
