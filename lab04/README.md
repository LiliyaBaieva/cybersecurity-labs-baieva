# 🔐 Спрощена Система Цифрових Підписів

Цей проєкт реалізує спрощену модель цифрового підпису, засновану на принципах асиметричної криптографії та хешування. Метою є демонстрація механізмів автентичності та цілісності даних.

**Генерація ключів**: Приватний та публічний ключі генеруються на основі персональних даних.

**Створення підпису**: Шифрування хешу документа "приватним ключем" (використовуючи оператор XOR як спрощену заміну).

**Перевірка підпису**: Розшифрування підпису "публічним ключем" та порівняння хешу.

**Виявлення підробок**: Демонстрація виявлення змін у документі.

## Опис

| Елемент | Формула Реалізації | Опис |
| :--- | :--- | :--- |
| Приватний ключ (PK) | int(SHA256(ім'я + ДН + слово)) | Хеш персональних даних, конвертований у ціле число. Використовується для створення підпису (зашифрування). |
| Публічний ключ (PUK) | (PK * 7) mod 1000007 |  Математично пов'язана величина, використовується для перевірки підпису (розшифрування). |
| Хеш Документу | SHA256(вміст файлу) | Обчислюється хеш від усього вмісту файлу для забезпечення цілісності. |
| Цифровий Підпис | хеш_документу XOR приватний_ключ | Спрощена заміна криптографічного шифрування. |
| Перевірка | (хеш_поточного_документу XOR підпис) == PUK | Спрощена перевірка: якщо PUK коректно відновлюється, підпис дійсний. |

## 🚀 Використання

**Вимоги**: Python 3.x

**Запуск**
1. Переконайтеся, що у вас є файл для підпису (наприклад, резюме.pdf або test.txt).

2. Запустіть скрипт: 

        -- python digital_signature_system.py

3. Введіть необхідні персональні дані та шлях до файлу, коли буде запропоновано.

### Приклад Виводу

Програма демонструє повний цикл роботи, включаючи:

1. **Генерацію ключів**: Виведення цілочисельних значень PK та PUK.
2. **Створення підпису**: Збереження підпису у файлі .sig.
3. **Перевірку ДІЙСНОГО підпису**: Підтвердження цілісності оригінального файлу.
4. **Виявлення ПІДРОБКИ**: Створення модифікованого файлу та демонстрація того, як зміна єдиного байта призводить до визнання підпису "ПІДРОБЛЕНИМ".
